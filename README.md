# Fuzzy-Decision-Support-System-for-Assessing-Children-s-Social-and-Emotional-Skills
---
## Introduction

Social and emotional skills influence children’s problem-solving ability, academic growth, affects their
long-term well-being, and personal development. This project aims to develop a fuzzy logic and machine learning expert system to provide a systematic
framework for assessing children’s social and emotional skills. The objectives
are to develop rule-based logic that enables systematic evaluation of children’s social and emotional skills, to
design and implement fuzzy expert systems that integrate these rules to generate assessment and to validate the
system using machine learning.

---

## Project Structure

- INT_01_ST_SELSkills(1).xlsx  # The dataset from the OECD Survey on Social and Emotional Skills
- ppval (1).py Social Skills Assessment
- fuzzy-model.py  # Fuzzy Model 
- analysis_result.py  #Fuzzy Model Result Analysis
- ml_validation.py  # Machine Learning validation
  
---

## Conclusion

In conclusion, the fuzzy expert system gave a clear and organized way to understand children’s social and
emotional skills. It helped classify students into simple levels—Needs Support, Developing, and Strong—and
offered feedback that schools can use when planning support. The machine learning validation also showed that
the system works consistently, which makes it a useful tool alongside regular evaluation.
